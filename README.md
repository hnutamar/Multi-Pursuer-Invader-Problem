## 📌 Project Overview
This repository contains the simulation framework, environment, and reinforcement learning models developed for the thesis *Adaptive Active Defense*. The project explores the Multiple Pursuer-Invader problem by proposing a hybrid defense architecture that combines kinematic artificial potential fields (vortex fields) with intelligent multi-agent reinforcement learning (MARL). 

The goal of the swarm (Pursuers) is to dynamically protect a moving target (Prime unit) against incoming threats (Invaders) in both 2D and 3D environments.

## 📁 Repository Structure
The project directory is organized as follows to separate the core logic, trained parameters, and evaluation metrics:

* `src/` - Main source code for the simulation environments and training scripts.
    * `models/` - Final pre-trained Reinforcement Learning models used in the thesis.
    * `data/` - Scripts for generating graphs, saved plots, and simulation metrics.
* `archive/` - Older test scripts, deprecated experiments, and legacy code.

*(Note: Training logs and large history files are excluded from the main branch to keep the repository lightweight).*

## ⚙️ Installation & Dependencies
To create a virtual environment and install the required dependencies (such as PyTorch, NumPy, and Matplotlib), run the following commands:

```bash
# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate

# Install requirements
pip install -r requirements.txt
```

## 🚀 How to Run the Simulator
Navigate to the source directory before running any scripts:
```bash
cd src/
```

**1. Evaluate the full defense swarm (Variants 1 & 2):**
Runs the main defense scenarios (Prime unit vs. Invaders) and generates evaluation metrics.
```bash
python test_defense.py 
```

**2. Evaluate isolated herding behaviors:**
Tests the RL herding models, calculates collision/win rates, and generates comparison charts.
```bash
python test.py
```

**3. Start a new training session:**
```bash
python train.py
```

## 🎛️ Configuration & Parameter Tuning
The framework is highly customizable. A wide range of parameters can be modified directly within the execution scripts (`test_defense.py`, `test.py`) or inside the dedicated configuration files (`sim_config2D.py`, `sim_config3D.py`):

* **Scenario & Swarm Setup:** Adjust the number of defending pursuers (`purs_num`) and attacking invaders (`inv_num`) to test different swarm scales.
* **Agent Kinematics:** Fine-tune the physical constraints of the simulation, including maximum speeds (`purs_speed`, `inv_speed`) and acceleration limits (`purs_acc`, `inv_acc`).
* **Environment Physics:** Change the simulation time-step (`dt`), boundary limits, or toggle environmental obstacles.
* **Visualization Tools:** Switch between different rendering modes by toggling the `SHOW_VISUALIZATION` (Matplotlib) and `PYBULLET` (3D physics engine) boolean flags directly in the code.
